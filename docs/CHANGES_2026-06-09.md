### 3. Flujo de consentimiento Myli (implementación completa)

**Archivo:** `js/mili-chat.js`

Se implementó el modelo de consentimiento híbrido aprobado por el cliente:

| Comportamiento | Detalle |
|---|---|
| Primer mensaje | Aviso de privacidad antes de cualquier interacción |
| Input deshabilitado | El usuario no puede escribir hasta elegir una opción |
| Dos botones | "✓ Sí" y "✗ No" — sin bloqueo total |
| Camino "Sí" | Acepta política → habilita input + chips + flujo completo |
| Camino "No" | Declina → habilita input + puede hacer preguntas generales |
| Estado de sesión | Solo en variables JS (sin localStorage) |
| Reset | `resetMili()` limpia consentimiento y vuelve a mostrar el aviso |

**Payload n8n actualizado:**
```json
{
  "sessionId": "myli_<timestamp>_<random>",
  "message": "<último mensaje del usuario>",
  "pageContext": { ... },
  "privacyConsented": true | false
}
```

### 4. Corrección del UX del flujo de consentimiento

**Problema:** La implementación inicial llamaba a `sendWelcomeMessage()` después de aceptar el consentimiento, generando un segundo saludo "¡Hola! Soy Myli..." duplicado.

**Solución:** Los handlers `handleConsentAccepted()` y `handleConsentInformationalOnly()` ahora inyectan directamente su mensaje de respuesta y siembran `miliHistory[]` sin llamar a `sendWelcomeMessage()`.

### 5. Texto aprobado del aviso de consentimiento

El aviso inicial de Myli quedó con el siguiente texto (3 iteraciones durante la sesión):

> ¡Hola! Soy Myli, bienvenido/a a mi chat.
>
> Antes de que iniciemos nuestra conversación, quería comentarte que al utilizar este canal está aceptando nuestra Política de Privacidad, la cual puede consultar en este enlace:
>
> 👉 Ver política de privacidad
>
> ¿Estás de acuerdo?

Seguido de los botones **✓ Sí** / **✗ No**.

### 6. Estilo de botones de consentimiento

**Antes:** El botón "✓ Sí" siempre se veía en rojo (fondo `#C2185B`) — apariencia de "ya seleccionado".

**Después:** Ambos botones arrancan con el mismo estilo de contorno gris. Al presionar cualquiera, el botón presionado cambia a rojo como confirmación visual.
